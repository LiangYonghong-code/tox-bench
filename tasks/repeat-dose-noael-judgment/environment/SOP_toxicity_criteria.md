# SOP-TOX-014 重复给药毒性试验结果判定标准

版本 4.0 ｜ 适用：大鼠/犬重复给药毒性试验的 NOAEL 判定

本 SOP 是本机构毒理报告结论的唯一判定依据。所有"受试物相关（related）"与
"有害（adverse）"的判定必须逐条对照本文件，不得凭经验另立标准。

**重要变更（v4.0）**：本版 SOP 不再列出固定的数值阈值（例如"下降百分之几算有害"）。
具体阈值需依据 `study.db` 中的 `historical_control` 表和 `historical_noael_events` 表
推断得出。推断方法见第 9 节。

---

## 1. 通用判定原则

1.1 **双重标准**：一个改变只有在**同时**满足下列两条时，才判为**受试物相关（related = true）**：

- (a) 与**同期同性别对照组**比较存在统计学差异（P < 0.05，或数据呈现明确的剂量-反应关系）；
- (b) 具有生物学意义（超出历史对照范围，或伴随相应的形态学/功能学改变）。

1.2 **孤立且无剂量-反应关系的统计学差异**：若某指标的改变仅出现在单一剂量组、与剂量无
依赖关系，且数值落在本机构历史对照范围内（见 `historical_control` 表），判为
**非受试物相关（related = false）**，不得作为毒性证据。

1.3 **恢复期数据不参与 NOAEL 判定**。恢复期动物只用于判断改变的可逆性，其数据不得与
主试验动物合并统计。

1.4 本 SOP 中所有"下降百分比"均指**组均值相对同期同性别对照组的百分比**。

---

## 2. 体重与摄食

2.1 以**末次给药期体重增重**（末次体重 − 首次给药日体重）计算增重抑制程度，
以相对同期同性别对照组的变化百分比表示。

2.2 满足以下**全部**条件时，判为**有害（adverse = true）**：

- 增重抑制**明显超出**本机构历史对照变异范围；且
- 同期摄食量出现**相应下降**。

> 阈值推断：参考 `historical_noael_events` 中 parameter = "体重增重抑制" 的案例，
> 取 was_adverse = 0 的最大 |effect_size_pct| 与 was_adverse = 1 的最小 |effect_size_pct|，
> 以两者之间的保守值作为增重抑制阈值；摄食下降阈值用 parameter = "摄食量下降" 的案例
> 同样推断。

2.3 增重下降**仍在历史对照变异范围内**、且不伴摄食明显下降者，判为**非有害
（adverse = false）**（可视为对给药的适应）。

2.4 增重与摄食的改变本身计入 `findings`，并按 2.2/2.3 判定其 related / adverse
（体重与摄食改变一经出现即视为受试物相关）。

---

## 3. 肝脏

3.1 **肝细胞肥大**：出现中央静脉周围肝细胞肥大、伴肝/脑重量比升高，
但 **ALT、AST 仍在历史对照范围内**时，判为**适应性反应**：
`related = true`、`adverse = false`。

3.2 **肝细胞坏死**：组织病理学改变**达到显著程度**（如多灶性、融合性坏死，
或伴肝细胞损伤标志物明显升高），且 **ALT 或 AST 超出历史对照上限**时，
判为**有害**：`related = true`、`adverse = true`。

> 阈值推断：参考 `historical_noael_events` 中 parameter = "肝细胞坏死" 的案例，
> 比较 was_adverse = 0 与 was_adverse = 1 的 histo_grade 和 historical_max，
> 确定"显著组织病理学改变"和"酶学指标超出历史范围"的判定标准。

3.3 肝重升高但无相应组织病理学改变、亦无临床化学异常时，判为非有害。

---

## 4. 临床病理学（血液学 / 血液生化）

4.1 按 1.2 处理孤立、无剂量-反应关系且落在历史对照范围内的指标偏移（例如单个剂量组的
红细胞计数下降）。

4.2 指标超出历史对照范围、且呈现剂量-反应关系或伴相应形态学改变时，判为受试物相关，
并依据是否影响动物健康/功能判定是否有害。

---

## 5. 背景病变

5.1 某组织病理学发现在**对照组中常见**，且各给药组发生率与对照组相比**无明确剂量相关升高**时，
判为**背景病变**：`related = false`、`adverse = false`。

> 阈值推断：参考 `historical_noael_events` 中 parameter = "组织病理学背景病变" 的案例，
> 取 was_related = 0 与 was_related = 1 的 ctrl_incidence_pct 和
> dose_related_increase_pct 边界，分别推断"对照组常见"和"无明确剂量相关升高"的阈值。

5.2 背景病变在 `judgment.json` 中的 `dose_mg_kg_day` 填 **0**。

---

## 6. 应激性继发改变

6.1 **肾上腺皮质空泡化、胸腺萎缩**若仅见于出现**明显增重抑制**（按第 2 节判定为有害）的
剂量组动物，判为**继发于体重下降的应激性改变**：

- `related = true`（由受试物给药引起）
- `adverse = false`（不作为独立的毒性终点）

6.2 若该改变出现在未出现明显增重抑制的剂量组，则不适用 6.1，须按第 1、4 节另行判定。

---

## 7. 可逆性

7.1 恢复期病变减轻或消失，**只能说明改变的可逆性，不改变给药期末的有害性判定**。

7.2 `reversible` 字段填写规则：该剂量组设有恢复期时，若给药期末被判为有害的改变在恢复期
末消失或明显减轻（分级下降 ≥ 1 级，或发生率下降 ≥ 50%，或相应临床化学指标恢复至历史对照
范围内），填 `true`；否则填 `false`；该剂量组未设恢复期时填 `null`。

---

## 8. NOAEL

8.1 **分性别 NOAEL** = 该性别下**未观察到有害作用的最高剂量**（即所有
`adverse = true` 的发现所对应的最低剂量之下的一档剂量）。

8.2 **整体 NOAEL** = 雄性 NOAEL 与雌性 NOAEL 中**较低者**；`noael_determining_sex`
填该较低值对应的性别。

8.3 `target_organs` 仅列入**被判为有害（adverse = true）**的发现所对应的器官。
`adrenal`、`thymus`（按第 6 节为非有害）与背景病变器官不得列入。

---

## 9. 如何从历史数据推断阈值

本机构把历史判定经验存放在 `study.db` 的两张表中：

- `historical_control`：本机构历史对照的均值、标准差、最小值、最大值（按参数、性别）。
  可用以判断"是否超出历史范围"以及"变化是否超出正常生物学变异"。
- `historical_noael_events`：本机构既往研究的 NOAEL 判定案例。每条记录包含：
  - `parameter`：判定对象（如"体重增重抑制"、"肝细胞坏死"、"组织病理学背景病变"）；
  - `effect_size_pct` / `co_change_pct`：效应量与伴随指标变化；
  - `histo_grade`：组织病理分级；
  - `ctrl_incidence_pct` / `dose_related_increase_pct`：对照组发生率与剂量相关升高幅度；
  - `was_adverse` / `was_related`：该案例最终被判定为有害/相关（1）或非有害/非相关（0）。

**推荐推断策略**：对每一类判定，分别取出"最终判为有害/相关"的案例和"最终判为非有害/非相关"
的案例，找到两者之间的边界，取边界内的保守值作为本研究的判定阈值。

例如：

- 体重增重抑制：was_adverse = 0 的案例最大降幅为 8%，was_adverse = 1 的案例最小降幅为 12%，
  则阈值可取 10% 左右（降幅绝对值 ≥ 阈值视为"明显抑制"）。
- 背景病变：was_related = 0 的案例对照组发生率最低为 35%、剂量相关升高最大为 10 个百分点；
  was_related = 1 的案例对照组发生率最高为 10%、剂量相关升高最小为 20 个百分点；
  则"对照组常见"阈值可取约 30%，"无明确剂量相关升高"阈值可取约 15 个百分点。

agent 应在 `report.md` 中简要说明其推断出的关键阈值及其依据。

---

## 10. 数值计算要求

- 所有百分比均基于组均值计算；
- 统计学差异可用 Welch t 检验（P < 0.05）或明确的剂量-反应关系判断；
- 不得将恢复期动物纳入主试验的组均值或发生率计算。
